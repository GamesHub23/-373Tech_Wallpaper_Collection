Getting Started.

Read these notes before applying a wallpaper. The exact Nugget version and iOS build matter.

ImportantMake a full backup before using any tweak tool. Classic Nugget and GoldenNugget are separate projects. Do not use classic Nugget on iOS 27.

Necessary before starting

  • An iPhone compatible with the chosen tool and iOS version.
  • A Windows PC with Apple Devices or iTunes installed.
  • A reliable USB cable and working USB port.
  • A full iPhone backup saved before making changes.
  • The correct Nugget / GoldenNugget release from its official GitHub page.
iOS 17–26

Classic Nugget

Use only a release that lists your exact iOS version as supported. Classic Nugget documentation does not establish iOS 16 support.

  1. Install Apple Devices or iTunes on Windows.
  2. Back up the iPhone.
  3. Download a compatible Nugget release.
  4. Connect the iPhone, unlock it and tap Trust This Computer.
  5. Open Nugget and verify device and iOS detection.
  6. Follow the PosterBoard instructions to apply the compatible wallpaper package.
  7. Wait for completion and follow on-screen reboot instructions.
Official Nugget repository ↗
iOS 27 / 27.2

GoldenNugget

For iOS 27, use GoldenNugget only if its latest release explicitly supports your exact build.

  1. Install Apple Devices or iTunes on Windows.
  2. Create and verify a full iPhone backup.
  3. Download GoldenNugget from its official repository.
  4. Connect and unlock the iPhone, then approve the Trust prompt.
  5. Confirm device and iOS detection in GoldenNugget.
  6. Use its PosterBoard section to import and apply a supported wallpaper.
  7. Keep the cable connected until the app finishes. Follow on-screen instructions.

iOS 27 support can change between releases. Confirm iOS 27.2 compatibility before proceeding.
